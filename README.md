 Financial Bill Tracker

 About the Project
The Financial Bill Tracker is an Android mobile application developed using Kotlin under the Financial Inclusion and Literacy theme. It is designed to help users manage bills, monitor payment deadlines, and keep track of their payment status.

 Problem Statement
People often struggle to keep track of recurring bills, due dates, payment amounts, and unpaid obligations. This can result in forgotten payments, penalties, service interruptions, and poor financial planning. Existing approaches such as paper records, calendars, or manual tracking can be inconvenient and unreliable.

 Proposed Solution
The Financial Bill Tracker provides a central mobile platform for recording and organizing bills, viewing due dates, tracking payment statuses, and managing financial obligations.
 Planned Features
- Bill recording and management
- Bill due-date tracking
- Paid and unpaid bill status
- Bill editing and deletion
- Bill categorization
- Upcoming bills overview
- Input validation and user feedback
 Technologies
- Kotlin
- Android Studio
- Android SDK
- GitHub for collaboration
